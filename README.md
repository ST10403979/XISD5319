## 📋 Overview

Spunky's Hairflair is a fully functional web-based booking system for a hair salon located in Mandalay, Mitchell's Plain. The system allows customers to register, browse services, select stylists, book appointments, pay deposits, and manage their bookings.

## ✨ Features

| Feature | Description |
|---------|-------------|
| 🔐 User Registration | Customers register with name, email, and phone number |
| 💇‍♀️ Service Catalog | Browse 6 hair services with pricing and duration |
| 👩‍🦱 Stylist Selection | Choose from 3 professional stylists with ratings |
| 📅 Date Picker | Select available dates (14 days in advance) |
| ⏰ Time Slots | Choose from 8 time slots (9 AM - 4 PM) |
| 💳 Deposit System | 50% deposit required to confirm booking |
| 📋 My Bookings | View all upcoming and past appointments |
| ❌ Cancel Booking | Cancel appointments when needed |
| 📱 Responsive Design | Works on mobile, tablet, and desktop |
| 💾 Persistent Storage | Data saved in browser LocalStorage |
